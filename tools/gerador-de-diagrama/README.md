# 📊 Gerador de Diagramas

> Geradores de **diagrama de sequência** e **máquina de estados** via Mermaid.

Duas ferramentas HTML standalone que renderizam diagramas a partir de uma
sintaxe simples. Baseado em [Mermaid.js](https://mermaid.js.org/).

---

## 🚀 Como usar

Abra o arquivo desejado no navegador (duplo clique):

- [`diagrama-sequencia-frend-v2.html`](./diagrama-sequencia-frend-v2.html) — Diagramas de sequência
- [`maquina-estados-v1.html`](./maquina-estados-v1.html) — Máquinas de estado

Escreva a sintaxe no editor à esquerda e veja o preview renderizado em tempo real.

---

## ✨ Recursos

- 🎨 Tema dark customizado
- ⚡ Preview ao vivo enquanto digita
- 📋 Botão para copiar o código Mermaid
- 💾 Exporta o diagrama como PNG/SVG

---

## 📁 Arquivos

| Arquivo | O que faz |
|---|---|
| `diagrama-sequencia-frend-v2.html` | Gerador de diagramas de sequência (FREND) |
| `maquina-estados-v1.html` | Gerador de máquinas de estado |

---

## 📝 Notas

- Requer conexão com a internet na primeira vez (carrega Mermaid via CDN)
