# 🔧 r.swisskit-forge

> Coleção pessoal de ferramentas pequenas e úteis — cada uma nasceu de uma necessidade real.

Ferramentas simples (HTML, Python, Shell) que criei ao longo do tempo.  
Sem dependências pesadas. Sem complicação. Só o essencial.

---

## 🗂️ Estrutura

```
r.swisskit-forge/
├── tools/
│   ├── nome-da-ferramenta/
│   │   ├── README.md     # o que faz e como usar
│   │   └── ...           # arquivo(s) da ferramenta
├── README.md
```

---

## 🛠️ Ferramentas

| Ferramenta | Descrição | Tipo |
|---|---|---|
| [`audiocut-pro-v2`](./tools/audiocut-pro-v2) | Corte de áudios em lote — glassmorphism, undo/redo, zoom, preview | HTML |

---

## 📐 Filosofia

- **Pequena** → no máximo 5 arquivos por ferramenta
- **Focada** → resolve uma coisa bem
- **Pronta** → abre e usa, sem setup complicado

---

## 🚀 Como usar

Cada ferramenta tem seu próprio `README.md` com instruções detalhadas.  
Clone o repositório inteiro, ou baixe só a pasta da ferramenta que precisa.

```bash
git clone https://github.com/ricardocamati/r.swisskit-forge
```
